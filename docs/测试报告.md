## 2. 构建

```powershell
# Debug（默认静态库，含测试与示例）
cmake -S . -B build/mingw -G Ninja -DCMAKE_BUILD_TYPE=Debug
cmake --build build/mingw --parallel 8
ctest --test-dir build/mingw --output-on-failure

# Release + 警告即错误
cmake -S . -B build/werror -G Ninja -DCMAKE_BUILD_TYPE=Release \
      -DRRC_CODEC_WARNINGS_AS_ERRORS=ON
cmake --build build/werror --parallel 8
ctest --test-dir build/werror --output-on-failure

# 共享库
cmake -S . -B build/shared -G Ninja -DCMAKE_BUILD_TYPE=Release \
      -DRRC_CODEC_BUILD_SHARED=ON -DRRC_CODEC_WARNINGS_AS_ERRORS=ON
cmake --build build/shared --parallel 8
ctest --test-dir build/shared --output-on-failure
```

## 7. 结论

方案第 9.1 节的静态库门禁（单元、黄金向量、53 消息 round-trip、CONTAINING、
信道校验、安装消费、生成一致性、健壮性基础用例）全部通过；构建时间与共享库体积
满足门禁。pycrate/v1 差分、MSVC、ASan 为环境限制未执行，已在第 6 节如实列出。
