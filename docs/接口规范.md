# RrcCodec 接口规范（v2.0.0）

> 对应库版本 `2.0.0`、C API 版本 `1`、ASN.1 版本 `3GPP TS 38.331 v18.10.0`
> （`NR-RRC-Definitions`）。本文件描述公开 C ABI；内部实现（位流、生成的编解码
> 函数、分派表）不属于公开接口。

## 1. 头文件

| 头文件 | 内容 |
|---|---|
| `rrc_codec/rrc_codec.h` | 伞头；`EncodedMessage`、4 个编解码函数、2 个版本函数、安全上限宏 |
| `rrc_codec/rrc_export.h` | `RRC_CODEC_API` 导出宏；静态库由构建系统定义 `RRC_CODEC_STATIC` |
| `rrc_codec/rrc_version.h` | 库版本 / C API 版本 / ASN.1 版本宏 |
| `rrc_codec/rrc_channel.h` | `ChannelType`（10 个信道，1–10） |
| `rrc_codec/rrc_error.h` | `ErrorCode`、`ErrorInfo`、`ErrorHandler`、`GetLastErrorInfo`、`SetErrorHandler` |
| `rrc_codec/types/rrc_types.h` | 全部消息/IE 的 C 结构体与枚举（生成伞头；实际定义拆分在 `types/rrc_types_partNNN.h`，单文件 <300 KB） |
| `rrc_codec/messages/rrc_messages.h` | `MessageKind`（53 个实际消息）与 `ChannelOfMessageKind` |

C99 基线：头文件不包含 C++ 类型；C++17 调用方直接包含同一套头（`extern "C"`）。
所有公开头均可单独包含，CI 用 `-std=c99 -pedantic-errors` 与
`-std=c++17 -pedantic-errors` 检查。

## 2. 公开函数（恰好 8 个）

| 函数 | 语义 |
|---|---|
| `ErrorCode EncodeMessage(MessageKind kind, const void* message, EncodedMessage* encoded)` | 按消息类型编码；`message` 必须指向 `kind` 对应结构体；成功时库分配 `encoded->data` |
| `void FreeEncodedMessage(EncodedMessage* encoded)` | 释放编码结果并清零；可传 NULL、可重复调用 |
| `ErrorCode DecodeMessage(ChannelType channel, MessageKind kind, const uint8_t* data, size_t size, void* message)` | 按信道 + 消息类型解码；`channel` 用于一致性校验；失败时输出结构体清空 |
| `void FreeMessage(MessageKind kind, void* message)` | 释放解码产生的动态内存并清零；只用于解码结果 |
| `ErrorCode GetLastErrorInfo(ErrorInfo* info)` | 取当前线程最近一次错误摘要（`code/channel/bitOffset`） |
| `void SetErrorHandler(ErrorHandler handler, void* userData)` | 预留接口：只保存，不触发回调 |
| `const char* GetVersionString(void)` | 库版本字符串 `"2.0.0"` |
| `const char* GetAsn1VersionString(void)` | ASN.1 版本字符串 `"18.10.0"` |

### 2.1 编码

```c
MIB mib = {0};
/* 填字段；OPTIONAL 字段先置 has_xxx = true */
EncodedMessage encoded = {0};
ErrorCode rc = EncodeMessage(MessageKind_MIB, &mib, &encoded);
if (rc == ErrorCode_Ok) {
    /* encoded.data / encoded.size / encoded.bitLength */
}
FreeEncodedMessage(&encoded);
```

- 编码器先写入该消息在所属信道包装层中的固定选择位，用户无感知；
- UPER，MSB first；完成后补 0 到字节边界；
- `OPTIONAL` 由 `has_` 标志决定；`DEFAULT` 等于默认值时位为 0 且不编码值；
- `CONTAINING` 字段是指向内层结构体的指针，库自动编码内层并加开放类型长度前缀；
- 失败时 `encoded` 被清零，无内存泄漏。

### 2.2 解码

```c
MIB decoded = {0};
rc = DecodeMessage(ChannelType_BCCH_BCH, MessageKind_MIB,
                   encoded.data, encoded.size, &decoded);
if (rc == ErrorCode_Ok) {
    /* 直接读字段；CONTAINING 指针已指向库分配的内层结构体 */
    FreeMessage(MessageKind_MIB, &decoded);
}
```

- 先校验 `ChannelOfMessageKind(kind) == channel`，否则 `ChannelMismatch`；
- 包装位与期望消息不一致：占位分支返回 `UnsupportedMessage`，其他消息返回
  `MessageKindMismatch`；
- 不要求输入长度恰好等于消息长度，尾随位忽略；
- 解码失败时内部释放已分配内存，输出结构体全零；
- 解码得到的数组/字符串/`CONTAINING` 内层结构体均由库 `malloc`，必须
  `FreeMessage` 释放，不得对编码自建结构体调用 `FreeMessage`。

### 2.3 C++ 使用

无独立 C++ API；直接包含 `rrc_codec/rrc_codec.h`，调用方式与 C 完全相同。库本身
用 C++17 构建，但公共 ABI 为纯 C。

## 3. 结构体映射（摘要）

| ASN.1 | C 表示 |
|---|---|
| 实际消息（53 个） | 顶层结构体 `MIB`、`SIB1`、`RRCReconfiguration` … |
| `SEQUENCE` | 结构体，字段按 ASN.1 声明顺序 |
| `CHOICE` | `<Name>_Tag tag; union { ... } u;` |
| `ENUMERATED`（不可扩展） | C `enum`，常量 `<类型>_<值名>`，序号即编码索引 |
| `ENUMERATED`（可扩展） | `int32_t` 别名 + `<类型>_<值名>` 宏；未知扩展值原样保留 |
| `INTEGER` | `int64_t`（命名类型生成 typedef） |
| `BOOLEAN` | `bool` |
| `BIT STRING` | `BitString { uint8_t* bytes; uint32_t bitLength; }` |
| `OCTET STRING` | `OctetString { uint8_t* bytes; uint32_t length; }` |
| `SEQUENCE OF` | `typedef struct X { T* items; uint32_t count; } X;`（匿名字段展开为 items/count） |
| `OPTIONAL` | `bool has_<field>;` + 值字段 |
| `DEFAULT` | 只有值字段；根位图仍占 1 bit |
| `CONTAINING` | `<Target>* field;`（NULL 表示未出现） |
| 扩展添加组 `[[ ]]` | `<Type>_ExtGroupN` 子结构 + `bool has_extGroupN;` |
| 空 `SEQUENCE {}` / `NULL` | 占位结构体 `_dummy`，编码 0 bit |

完整定义以生成头 `types/rrc_types.h` 及 `generated/rrc_message_index.md` 为准。

## 4. 错误码

| 错误码 | 触发场景 |
|---|---|
| `ErrorCode_Ok = 0` | 成功 |
| `InvalidArgument = 1001` | 空指针、非法枚举值、非法 size |
| `UnsupportedChannel = 1002` | `channel` 不在 1–10 |
| `OutOfMemory = 1003` | 内存分配失败 |
| `NotImplemented = 1004` | 预留接口 |
| `ValueOutOfRange = 2001` | INTEGER / 长度超出 ASN.1 约束 |
| `InvalidBitString = 2002` | BIT STRING 长度或指针非法 |
| `InvalidOctetString = 2003` | OCTET STRING 长度或指针非法 |
| `InvalidEnumValue = 2004` | 枚举值不在允许集合 |
| `InvalidChoiceTag = 2005` | CHOICE tag 与 ASN.1 不匹配 |
| `MissingMandatoryField = 2006` | 必填字段缺失（如 `CONTAINING` 为 NULL） |
| `TruncatedInput = 3001` | 输入码流不足 |
| `InvalidLength = 3002` | 长度行列式非法 |
| `LengthOutOfRange = 3003` | 长度/元素数超出约束或上限 |
| `IntegerOutOfRange = 3004` | 整数编码超出约束 |
| `InvalidEnumeratedIndex = 3005` | 枚举索引非法 |
| `InvalidChoiceIndex = 3006` | CHOICE 索引非法 |
| `InvalidOptionalBitmap = 3007` | OPTIONAL 位图越界 |
| `InvalidExtensionBitmap = 3008` | 扩展位图非法 |
| `UnsupportedExtension = 3009` | 出现 v18.10.0 之外的扩展内容 |
| `OpenTypeOverrun = 3010` | 开放类型长度越界 |
| `ChannelMismatch = 3011` | 解码 channel 与消息类型所属信道不一致 |
| `MessageKindMismatch = 3012` | 包装选择位指向另一条实际消息 |
| `UnsupportedMessage = 3013` | 包装选择位命中 spare/占位分支 |
| `ContainingDepthExceeded = 3014` | `CONTAINING`/开放类型嵌套超过上限 |
| `InternalError = 9001` | 内部错误兜底 |

首版 `GetLastErrorInfo` 只填 `code/channel/bitOffset`；`fieldPath`、`message` 恒为
NULL。`SetErrorHandler` 只保存参数，不触发回调。

## 5. 安全上限（编译期可覆盖）

| 宏 | 默认值 |
|---|---:|
| `RRC_CODEC_MAX_INPUT_BYTES` | 16 MiB |
| `RRC_CODEC_MAX_OPEN_TYPE_BYTES` | 8 MiB |
| `RRC_CODEC_MAX_SEQUENCE_OF_COUNT` | 65,536 |
| `RRC_CODEC_MAX_BITSTRING_BITS` | 65,536 |
| `RRC_CODEC_MAX_CONTAINING_DEPTH` | 16 |

CMake 变量同名，通过 `target_compile_definitions(... PUBLIC)` 同时作用于库与消费者。

## 6. 所有权与线程安全

- 编码输入结构体及其指针归调用方，库只读、不接管；
- 编码输出 `EncodedMessage.data`、解码输出中的所有动态内存归库分配，分别用
  `FreeEncodedMessage` / `FreeMessage` 释放；
- 函数无共享可变状态；`GetLastErrorInfo` 为线程局部；同一编码结果/消息对象不得并发读写。

## 7. 版本与 ABI

- 语义版本 `2.0.0`，SOVERSION `2`；
- 结构体 ABI 与 ASN.1 v18.10.0 绑定，ASN.1 升级视为 ABI 破坏；
- 2.x 内已有函数签名不变，新增消息只追加 `MessageKind` 数值；
- 不承诺跨编译器/字长/ASN.1 版本的二进制兼容。
